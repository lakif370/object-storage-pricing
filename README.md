## 先说为什么"便宜"这个词，得换种方式理解

很多人对比对象存储价格，习惯性地去看"每 GB 存储多少钱"。七牛云标准存储后付费是 0.115 元/GB/月，阿里云 OSS、腾讯云 COS 也都在 0.12 元上下浮动，看着挺便宜对吧？但问题在于，这只是存储费。你往外下载文件，还得掏外网流出流量费，七牛云是 0.26 元/GB，阿里云也差不多。请求次数另算，CDN 回源另算。一个月下来，存储费可能只占账单的三分之一，剩下的全是流量和请求堆出来的。

雨云的思路不太一样，它走的是**套餐制**。你买一个套餐，存储空间和流量都打包给你，用超了才按量补。更关键的一点——**它不计算下行流量，只计算上行流量**。翻译成人话就是：你往对象存储里上传文件，不扣流量；只有别人从你的对象存储里下载东西，才扣套餐里的流量配额。对于大部分小站来说，上传量本来就远小于下载量，但雨云这个计费方式等于把"上传"这个动作彻底免费了，只对"被下载"收费。

还有个隐藏福利：如果你的云服务器和对象存储在**同一个区域**，走内网地址互相传文件，上下行都不算流量。这意味着你要是把站点搭在雨云的服务器上，再把对象存储挂在同区，服务器从对象存储取文件喂给用户，这中间的内网传输是零流量成本的。这一条对小站长来说省得相当实在。
